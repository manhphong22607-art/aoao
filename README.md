# aoao

This repository provides a Codex skill for converting files to Markdown with [MarkItDown](https://github.com/microsoft/markitdown).

## Install

~~~bash
python -m pip install -r .codex/skills/markitdown/requirements.txt
~~~

## Use

~~~bash
markitdown path/to/input.pdf -o output.md
~~~

The skill instructions are in [.codex/skills/markitdown/SKILL.md](.codex/skills/markitdown/SKILL.md).
